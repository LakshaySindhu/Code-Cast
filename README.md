# CodeCast

CodeCast is a collaborative coding platform designed to help users share, edit, and discuss code in real-time.

## Features

- Real-time code editing and sharing
- Syntax highlighting for multiple languages
- User authentication and session management
- Chat and discussion panel
- Responsive UI

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

## Installation

Clone the repository:

```bash
git clone git@github.com:LakshaySindhu/Code-Cast.git
cd CodeCast
```

Install dependencies for both client and server:

```bash
cd client
npm install
cd ../server
npm install
```

## Running the Application

### Run Client Side

```bash
cd client
npm start
```
The client will start on [http://localhost:3000](http://localhost:3000).

### Run Server Side

```bash
cd server
npm start
```
The server will start on [http://localhost:5000](http://localhost:5000) (or your configured port).
